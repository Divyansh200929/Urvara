# Urvara
Retro 90s Windows 95-styled 5-in-1 Soil Fertility &amp; Telemetry Monitor for Arduino Uno + RS-485 Modbus RTU sensors. Tracks real-time Nitrogen (N), Phosphorus (P), Potassium (K), Soil pH, and Moisture (%) with automated crop recommendations, fertilizer advisories, live trend plotting, and CSV data logging.
